KOGG Presenter for Windows - 0.1.0 preview
Worship without Limits

Install, open KOGG, choose Local, and start presenting. No account, Node,
terminal command, or server setup is required. KJV, BSB, KJV Strong's,
the Strong's lexicon and 300 traditional hymns are included in the installer.

Requires Windows 10/11 x64 and Microsoft Edge already installed. Edge is
the display engine, which keeps this download small. This preview installer
is not code signed. Download only from the official KOGG GitHub release.

Use Output to open the presentation window. Allow screen-management
permission if offered for automatic extended-screen placement. Fullscreen
and placement still depend on Edge and Windows permissions.

Choose Local to save songs, plans and imported media on this computer.
Base keeps a temporary session. Sync requires an internet connection and
your KOGG account. Browser and desktop libraries are separate: sign in to
Sync or import your library backup to move existing work to this edition.

Phone remote: Stream > Phone remote (online) > Start, then scan with your
phone. Both devices need internet; no Sync account or bridge is needed.
The direct Wi-Fi browser option is experimental and needs a return pairing
exchange. It is not a one-scan, six-digit offline connection.

Online lyrics search and additional Bible downloads require internet.
Speech recognition availability and connectivity depend on Edge.

The small KOGG icon beside the Windows clock keeps local output available.
Double-click to reopen KOGG; right-click > Quit after closing your output.
Installing an update requires quitting KOGG there first. No startup entry,
Windows service, firewall exception or network-wide listener is installed.

Uninstall from Windows Settings > Apps. Your Local/Sync browser profile is
kept at %LOCALAPPDATA%\KOGG Presenter\Browser, so reinstalling retains work.
Export a library backup before moving computers. Uninstall does not erase
that profile or touch the OBS plugin.

Preview acceptance: software checks are included in the repository.
Rehearse with your actual projector, phone and OBS before a live service.

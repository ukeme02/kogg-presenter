## Findings and priorities

1. **High — existing Bible encoding corruption remains.** A targeted scan of all 13 bundled Bible JSON files flags 1,863 KJV verses and 1,932 ASV verses containing mojibake markers. This is a character-integrity screen, not a full textual comparison with authoritative editions. KJV 2 Kings 7:9 contains `king\u00e2\u20ac\u2122s` rather than a correctly encoded apostrophe. Other scanned Bible files did not match these marker patterns; that does not establish complete textual accuracy. Bible files were not changed in the 14 commits.
2. **High — release/data freshness risk in the new cache strategy.** sw.js copies old HTML, JS, CSS and data into each new cache and only fetches missing files during installation. Requests return the old shell while refreshing individual files later. This can expose stale/mixed-release assets on a first launch. Bible JSON is cache-first without revalidation, so correcting a Bible file at the same URL will not update an existing device without explicit invalidation/migration. Test a realistic v96/v97 → next-release upgrade online, then offline, with changed shell and Bible content.
3. **Medium — confirmed Lyrics single-tap emphasis failure.** js/app.js pointer-down immediately writes a one-word highlight; pointer-up sees that newly written highlight and clears it. Executing the actual handler block in a VM confirms: down=true, completed tap=false. Drag selection may work; a first single-word tap does not persist. Existing suite misses the complete tap gesture.
4. **Medium — quick size/alignment can switch the prepared service theme.** Prepared service items now use an item-specific theme, but patchTheme/quickFontSize/quickCycleAlign still edit currentThemeId and push that theme live. If a service item's live theme differs from the operator's selected theme, a quick edit can switch backgrounds/fonts rather than just adjust the intended live look. Audit this interaction and long-text auto-fit limits.
5. **Medium — earlier requested functionality remains incomplete.** Default themes/new themes are still 7vh (control maximum 15vh); the app still has the old Quick Edit panel, not a floating Explorer settings widget. The hero “knowledge” annotation is completed. These should be tracked separately from regressions introduced by the new commits.
6. **Low — install-success feedback references an out-of-scope variable.** btnInstallApp's accepted branch uses pl.name, but pl is local to showLocalPanel. The swallowed ReferenceError can prevent the success message and button-hiding update even if installation succeeds. Reproduce with a mocked accepted install prompt before changing it.

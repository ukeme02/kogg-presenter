# Functionality audit — 10 November 2026

## Findings fixed in v127

1. **Landing animations appeared stopped together.** The test browser reported reduced motion; newer CSS disabled all animations even while the older script applied a `motion-enabled` class. CSS and both preview scripts now share one saved preference. System-reduced motion remains respected until a visitor chooses **Enable motion**. Their choice persists, and the footer can restore reduced motion. Offscreen loops still pause to save work.
2. **Duplicate NLT controls.** Removed the obsolete disabled NLT placeholder beside the connected online NLT option. Provider/network/licensing requirements are unchanged.
3. **Windows opening flow.** Native startup initially surfaced Edge's browser-profile setup. The app invocation now disables browser sync/first-run UI and uses a separate persistent profile. A second launch visibly reached KOGG's mode selector without that prompt.
4. **Redundant installation prompt.** Windows Local mode correctly recognised the app but still offered a second browser installation when an install event was available. Both native and installed-browser flows now hide that prompt; three regressions cover the branches.
5. **New download layout.** Four download cards use a balanced two-by-two desktop/tablet grid and one column on phones. Removed the old three-card layout's last-card span.

## Simple remote instructions

1. Keep KOGG open on the laptop in Base, Local or Sync.
2. Open **Stream → Phone remote · online → Start / renew online remote**.
3. Scan the QR with the phone's normal camera and open the link.
4. Use **Previous, Next, Blank, Resume**. Both devices need internet; no KOGG account or bridge is required. Stop remote on the laptop revokes the link.

For fully offline use, the included desktop content presents without internet. Phone pairing is a separate requirement: the direct Wi-Fi browser preview still needs both sides to exchange pairing information; it is not a verified one-scan, six-digit offline flow.

## Windows delivery

The presenter installer is separate from the OBS plugin. It uses installed Edge to keep the download near 6.2 MB and includes the three core Bibles, lexicon and 300 hymns. No Node or server setup is exposed to the user. The automatic private host listens only on 127.0.0.1:8768; saved data stays in a separate Edge profile across updates/uninstall. The preview is unsigned. See `docs/releases/desktop-v0.1.0-preview.md` for setup and limitations.

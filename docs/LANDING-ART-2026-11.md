Generated with the built-in image-generation tool for this project. The generator returned 1672 × 941 source images even though the prompts requested 4K. The 3840 × 2160 WebP files are resized exports, not native 4K generations. Responsive 640, 1280 and 1920 versions prevent phones from downloading the largest files.

Final project assets: `images/landing/light-{640,1280,1920,3840}.webp` and `images/landing/sanctuary-{640,1280,1920,3840}.webp`. The complete set is about 1.3 MB; a 640px light image is about 12 KB, and its 1280px version is about 39 KB. These decorative images are not mandatory Base precache downloads. They are included in the Windows package so its local landing page can render them without internet.

The blue sculptural image anchors the hero and final invitation. The church illustration supplies atmosphere behind the service demo; it is not represented as a photograph of a customer installation. Real interactive previews remain HTML, not generated screenshots. Existing KOGG wordmarks and Nunito typography are retained.

Motion starts automatically without a prompt or stored opt-in. OS reduced-motion is respected; offscreen/hidden-page pauses and focus protections remain. No third-party animation library was added.

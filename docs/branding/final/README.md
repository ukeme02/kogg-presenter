# KOGG Presenter — Folded K Screen

Chosen direction: C, refined with a presentation screen and stand.

- Primary symbol: icons/kogg-symbol.svg (blue, light backgrounds).
- Dark backgrounds: icons/kogg-symbol-light.svg.
- One-colour versions: icons/kogg-symbol-white.svg and icons/kogg-symbol-ink.svg.
- App icon: icons/icon.svg, plus PNG 192/512 and maskable SVG/PNG.
- Wordmark: supplied KOGG artwork, with Presenter in Nunito Sans Expanded beneath.
- Tagline: Worship without limits.

Use the unboxed symbol left of the wordmark at roughly the full height of both text lines. Keep the Presenter subtitle centred under KOGG. Preserve equal margins around the symbol and do not add shadows, gradients or extra symbols inside it. The screen silhouette makes the presentation cue clear; the K remains readable alone.

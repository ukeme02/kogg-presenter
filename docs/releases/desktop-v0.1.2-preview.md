# KOGG Presenter 0.1.2 — Windows preview

This refresh includes managed online NLT, projector attribution, anonymous usage reporting with retry, and reference-only NLT service schedules. KJV, BSB, KJV Strong's, Ibibio and 300 hymns still work offline after installation. NLT needs internet to load a passage and is not bundled.

Run the setup to update the installed program. Existing libraries stay in the separate browser profile. Windows 10/11 x64 and Microsoft Edge are required. No Node or manual server setup is required. This remains an unsigned preview.

Checksums accompany the installer. Do not put API keys into the app's public files; KOGG's managed key is stored only on its server.

# KOGG Connect 0.1.2 — NLT renderer support

Updates the bundled OBS renderer to show NLT copyright, stop displaying expired licensed text, and queue anonymous view reports when offline. Close OBS before installing, then reopen it and use the existing KOGG pairing.

Windows x64 and OBS 32.x are required. This is an unsigned preview; physical OBS acceptance remains pending. The plugin does not add video transport: use Window Capture for video. No Bible pack or API secret is included.

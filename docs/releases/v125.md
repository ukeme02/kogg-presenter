# KOGG Presenter v125 — Take your service with you

Images and videos can now travel with saved service schedules in Sync mode. Sign in on another device, load the plan online, and wait for **Ready offline here** before disconnecting.

## Use KOGG

- **Most churches:** [Open KOGG Presenter](https://kogg-presenter.pages.dev/index.html). No download or account is needed to start in Base. Wait for Ready offline; optionally install it from your browser's menu.
- **Self-hosting:** `kogg-presenter-v125-web.zip` contains the deployable web files and setup notes. This is a web package, not a Windows/macOS installer. Serve it over HTTPS or localhost; do not open index.html by double-clicking it.
- **OBS:** [KOGG Connect 0.1.0 Windows preview](https://github.com/ukeme02/kogg-presenter/releases/tag/kogg-connect-v0.1.0-preview) is a separate optional OBS plugin.
- GitHub's source archives contain the full repository at this release. `SHA256SUMS.txt` verifies the web package.

## Changes

- Private media storage with account-only access and a 50 MiB limit per file.
- Resumable uploads, content-based duplicate prevention and verified downloads.
- Only media used by current/saved service plans uploads; only the opened service downloads automatically.
- Clear cloud-saved and device-ready states, with retry and missing-file guidance.
- Fixed untouched factory themes blocking the first Sync on a new device. Conflicting user edits are still protected.
- Updated the landing page with travel and media guidance.

## Verification and limits

307 automated tests passed. Real PNG/MP4 upload, download, duplicate prevention and private-access checks passed against production storage. A downloaded MP4 decoded successfully. Fresh-cache testing simulates another device; rehearse on the actual presentation device before a service.

Base and Local keep media on their device. Sync needs internet to transfer files and a signed-in account. Prepare each device before disconnecting; browser storage can be cleared or evicted. Local videos may be up to 250 MiB, but cloud files must be 50 MiB or smaller. Video codec support varies. Media files are not embedded in JSON backups or transferred to the OBS plugin; Window Capture can capture the complete output.

Native Android/iOS apps, casting and Service Copilot remain planned. The browser app runs on compatible Windows, macOS, Linux, ChromeOS, Android and iOS browsers.

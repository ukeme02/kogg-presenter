# KOGG Presenter v138 — Current offline downloads

The Windows presenter and OBS plugin downloads now follow the current app rather than older browser builds. The Windows edition includes the full Ibibio Bible; extra Bible packs remain optional. No new runtime dependency or audio library has been added.

The OBS package includes the previously omitted media-display scripts and validates renderer dependencies during its build. This does not add video transport to OBS; Window Capture remains the media fallback.

NLT continues through Tyndale until its announced 1 January 2027 closure. After that date, unfetched chapters fail with a clear explanation instead of calling the retired endpoint. API.Bible replacement account setup and edition approval are in progress; replacement access is not yet activated.

This ZIP is for HTTPS or localhost self-hosting, not a native installer. See WEB-SETUP.txt inside. For normal offline Windows use, choose the separate Windows presenter preview. Online lyrics, Sync, connected translations and online phone remote still require internet. Keep credentials out of public web files.

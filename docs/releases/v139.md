# KOGG Presenter v139 — NLT connected

NLT now loads through KOGG's secure server connection. Select NLT, type a passage and present; no personal API key or account is required in Base or Local mode. Only requested chapters load, with a small session cache and server cache to avoid repeat provider requests. The four offline Bibles and hymnary are unchanged.

The projector shows the provider's copyright notice. Anonymous usage reporting retries after connectivity failures without interrupting projection. Service plans and Sync save NLT references; text loads when presented on the receiving device. NLT is not a full offline download. Expired content is not projected, and provider limits or outages produce a clear message while preserving the current output.

Fixes include initializing the connected-Bible provider, avoiding an unnecessary chapter-one request on Quick Jump, preventing stale requests from replacing newer output, and keeping expired search content out of results. The landing page explains the new connection.

Windows Presenter and KOGG Connect installers are refreshed to 0.1.2-preview. Existing installed users should update to receive the new renderer and reporting support. No heavy SDK or runtime dependency was added.

For self-hosting, configure the server-side `API_BIBLE_KEY` and endpoint/origin policy. No secret is included in this ZIP. Automatic tests and isolated Edge checks cover NLT, service replay, attribution, expiry and reporting; physical projector and OBS hardware acceptance remain separate.

Release update, 20 November: the web ZIP includes server compatibility fix `c25f3be` on top of the v139 tag (`668802f`). Cloudflare requires manual redirect handling; redirects remain rejected without forwarding credentials. The Windows/OBS client installers are unchanged by this server-only correction. Production NLT fetching, projection and usage acknowledgements now pass, along with all 376 automated checks. The downloadable ZIP and checksum have been refreshed together.

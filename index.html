        Scripture versions
        Add a Bible version

        Import any translation as a JSON file — { "translation": "Name", "books": [ { "name": "Genesis", "chapters": [ ["verse 1", "verse 2"] ] } ] } (66 books in order). It is stored on this device and appears in the translation list.

        Licensed versions (live online)

        Copyrighted translations can't be bundled or downloaded here. Instead they stream straight from the official services while online: NLT is a free live connection via Tyndale's NLT API. NIV, NKJV, NASB, CSB, Amplified and The Message stream through your own free API.Bible key — the Starter plan licenses up to three copyrighted versions for non-commercial church use. The key stays on this device only and is never published with this app.

        Strong's Numbers (KJV with Strong's)

        When the "KJV with Strong's" translation is live, the small word numbers appear in the On the projector preview — never on the projector itself (the congregation sees clean text). Tap a number and its Hebrew/Greek meaning takes the screen while the service continues; tap it again to flip back to the verse.

        Turns the tap-to-define word numbers on or off.

        Extra
        Voice Control

        Open the ⋯ menu in the top bar and tap 🎤 Speak, then just talk. Commands: "next", "previous", "blank", "logo", or a scripture like "John three sixteen" / "Psalms twenty-three", or a song title. Say "stop listening" to turn it off. Voice input uses the Web Speech API — works in Chrome/Edge and needs an internet connection (browser limitation, not KOGG).

        How the output works

        Output opens display.html — the clean full-screen view for your projector.

        • Phone/tablet → projector: mirror or cast the output screen (HDMI adapter or Chromecast), press ▶ Output, then rotate your phone to the display when you connect.

        • Laptop + projector: open display.html in a Chrome window on the projector screen and this operator page on your laptop screen — they stay in sync automatically (same browser). Press F11 for full screen.

        • Type a book name anywhere in Scripture to start Quick Jump. Keyboard shortcuts: ←/→ slides, Alt+B blank, Alt+L logo, Esc back to normal.

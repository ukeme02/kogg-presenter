Wi-Fi or mobile data. The devices can use different internet connections. No bridge is needed for online pairing.

Private pairing & stopping the remote

Share the QR code or link only with your operator. It grants presentation control for up to 12 hours. Start again for a new link, or press Stop remote on the laptop to revoke it. Stopping remote leaves the projected slide in place. Controls pause if the connection drops.

Direct Wi-Fi · no internet or bridge Preview

Prepare the laptop and phone remote online once. On the same Wi-Fi, open Stream → Phone remote · direct Wi-Fi. Scan the laptop’s code with the saved phone remote, then let the laptop scan the phone’s reply. Controls then travel directly between devices.

Two scans are needed for offline browser pairing. Keep both pages open. A laptop camera is needed for the reply scan; copying the reply code is the fallback. Guest-network isolation or a firewall can block the connection. Physical phone-and-laptop testing is still in progress.

Advanced fallback: offline Wi-Fi bridge

Fully offline Wi-Fi control currently uses the optional local bridge on the laptop. This is separate from the normal scan-and-connect option above.

Connect both devices to your trusted church network. Start node tools/obs-relay.cjs --remote, open its local operator, then choose Stream → Advanced · offline Wi-Fi (bridge). Your firewall and router must allow the connection. The OBS plugin does not replace this phone server.

Window Capture setup

  1. Open KOGG in your browser, click Output, and send a verse live. Keep that single output window open.

  2. In OBS, choose Sources → + → Window Capture, then select KOGG Presenter — Output from the window list. You are capturing the browser window; there is no need to add a Browser Source first.

  3. Fit the capture to your scene and check the preview. Use KOGG normally; OBS captures what the output shows. If a browser border appears, use fullscreen or crop the edges in OBS. Keep the output open and avoid minimising it.

Window Capture shows the complete output image, including its background. For a transparent overlay, use Option 2. On newer macOS versions, choose macOS Screen Capture and select the output window.

Windows x64 · OBS 32 · preview release. Installer is not yet digitally signed. Real OBS rendering and browser-permission checks are still pending.

Install and pair in three steps

  1. Close OBS, run the installer, then reopen OBS. Choose Sources → + → KOGG Presenter.

  2. Copy the eight-character code in the source properties. In KOGG, choose Stream → KOGG Connect, enter it and press Connect OBS. Allow local-network access if your browser asks.

  3. Choose the output style in OBS. Send a verse and check its preview. For a lower third, choose Separate broadcast and set Stream → Layouts → Lower third.

After pairing, the browser remembers the connection and retries when OBS reopens. The plugin includes its display files for offline use; wait for KOGG’s “Ready offline” before disconnecting internet. No Node installation or separate terminal is needed for this OBS connection.

Use Add existing to reuse the source across scenes. Disconnect in KOGG to clear the feed; revoke saved pairings in the OBS source properties. This plugin connects the same computer only; phone remote setup is separate.

Manual package & source ↗
Advanced fallback: local bridge Separate setup

  1. Start the local bridge.

    On the same computer as OBS, download the KOGG project and install Node.js from nodejs.org if needed. From the project folder, run node tools/obs-relay.cjs. Keep that terminal open.

  2. Open the local presenter.

    In Chrome or Edge, open http://127.0.0.1:8766/. This local workspace is separate from the website. Use a library backup to transfer saved work if needed.

  3. Choose your feed in Stream.

    In the local presenter, open Stream → Browser Source. Choose Separate broadcast for an independently styled feed, or choose the full presentation, transparent slides or graphics only. Copy its URL. In your scene, choose Sources → + → Browser. Keep Local file off, paste the URL below, and set Width and Height to your canvas size—for example, 1920 × 1080. Use 30 FPS if setting a custom frame rate.

  4. Display a verse and check the scene.

    Send Scripture live from the local presenter. Place the Browser Source above your camera source for a transparent overlay. Use Blank in KOGG to clear it. If it stays blank, check the bridge is running, the source is visible and a verse is live; then refresh the Browser Source.

For a solid slide background, remove ?overlay=1 from the URL.

The website URL alone will not sync your live verses into OBS: OBS uses a separate browser. Keep both the local presenter and bridge running on the OBS computer.

Speak or type your service brief. Copilot would assemble the order, match content from your library and connected sources, and flag missing files or uncertain matches. A FEW PRACTICAL ANSWERS

Before the
service starts.

Go to the app ↗
What really works offline?

After the app reports Ready offline, its interface, three core Bibles, Strong’s lexicon and basic hymnary are cached. Saved songs and previously downloaded packs work offline. Connected Bible passages, online lyrics search, sign-in and sync need internet. Browser storage can be cleared or evicted, so check readiness before a service.

Can I control KOGG from my phone without an account?

Yes. In Base, Local or Sync, open Stream → Phone remote · online on the laptop, press Start and scan its QR code with your phone. Both devices need internet, through Wi-Fi or mobile data. You do not need an account, installation or local bridge. Pairing does not upload your library or change your work mode. See the three steps.

Will my work travel to another device?

Use Sync mode and sign in to the same account. Saved songs, service plans, themes and scheduled images/videos travel with your account. Wait for Cloud saved before leaving. On the next device, open the plan online and wait for Ready offline here. Media uploads once and downloads only when its service is opened; the cloud limit is 50 MB per file. Imported custom Bible files are device-local; use a full backup to transfer them.

What happens to lyrics in Base mode?

They stay in the current tab’s session workspace, including the draft and temporary Service items. A refresh preserves that workspace. End session clears it without deleting a saved Local/Sync library or the hymn packs. Save in Local or Sync when you want a permanent copy.

Can I use NIV, NLT or an Efik Bible?

Connected NLT and API.Bible translation controls are implemented. They need internet; API.Bible versions also need your own key and suitable account access. Provider limits and terms apply. Efik is not currently bundled. Compatible Bible JSON imports are available in Tools; connected access does not create an unrestricted offline download.

Does the microphone work offline?

The Speak buttons can fill Quick jump and Whole search, and voice commands can navigate the service. Chrome/Edge speech recognition may require internet and microphone permission. Keyboard and touch controls remain available. KOGG does not include music or audio-file playback.

How do I connect a projector or OBS?

Set your displays to Extend and click Output. In Chrome or Edge, allow the screen-management popup so KOGG can place the output on your extended screen and follow it when reconnected. If you previously blocked it, review the site permissions from the browser’s address-bar site controls. KOGG attempts fullscreen where allowed; otherwise click the output once. Ordinary clicks no longer exit fullscreen—press Esc to leave. Some browser setups offer an Automatic fullscreen site setting; it is optional and may not be available. Other browsers may require a manual move. Repeated Output clicks reuse the existing window; the duplicate guard applies within the same site and browser profile. For OBS, the easiest option is Window Capture: select your already-open KOGG Output window. No Node.js or local bridge is needed for that option. For transparent output, the new Windows KOGG Connect plugin is available as a preview. The optional local bridge remains an advanced fallback. The hosted app and OBS do not automatically share browser storage. Follow the OBS setup steps. Read the setup guide ↗

Where do online lyrics come from?

Christian songs & hymns is the default online scope, searching Hymnary. Import a supported Hymnary or hymnal.net hymn page directly into slides. All music sources optionally searches LRCLIB and lyrics.ovh. Google opens a web search targeted to Christian sites in Christian scope; it does not automatically import Google results. Supported links also include LRCLIB and lyrics.ovh API links. Hymnary imports require text marked Public Domain; other unsupported pages use copy/paste. Review imported words and keep the supplied credits; source availability does not grant every kind of reuse permission.

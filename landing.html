HOW THE ROOM SEES IT

One screen for you.
One for the room.

KOGG treats the projector as a second working surface, not a mirror of your laptop. You keep every control; the room only ever sees the verse or lyric of the moment.

01

Connect the room screen

Plug the projector or TV into your laptop as a second display. On Windows press Win + P and choose Extend. On a Mac, untick Mirror Displays so both surfaces stay separate.

02

Keep the desk on your side

Present from the operator page on your main screen — docks, reading history, live preview and search never leave your side of the wall.

03

Send it next door

Set your computer displays to Extend, then press Output in Chrome or Edge. Allow the browser’s screen-management permission when prompted so KOGG can detect and use your extended screen. Output reuses its window. If fullscreen does not start automatically, click the output once. Further clicks keep it fullscreen; Esc exits.

04

Present without the wheel

Everything you fire — a verse, a lyric slide, a lower third — follows instantly between your window and the room. No refresh, no spinner, and nothing for the congregation to see but the words themselves.

SCRIPTURE ON YOUR STREAM / AVAILABLE NOW

Bring the Word
into OBS.

Two ways to show KOGG in OBS today. Start with Window Capture—no extra setup. Our fuller OBS workflow for Scripture, lyrics and alerts is coming later.

OPTION 1 / RECOMMENDED / NO EXTRA INSTALL

Capture your open Output window.

  1. Open KOGG in your browser, click Output, and send a verse live. Keep that single output window open.

  2. In OBS, choose Sources → + → Window Capture, then select KOGG Presenter — Output from the window list. You are capturing the browser window; there is no need to add a Browser Source first.

  3. Fit the capture to your scene and check the preview. Use KOGG normally; OBS captures what the output shows. If a browser border appears, use fullscreen or crop the edges in OBS. Keep the output open and avoid minimising it.

Window Capture shows the complete output image, including its background. For a transparent overlay, use Option 2. On newer macOS versions, choose macOS Screen Capture and select the output window.

OBS Window Capture guide ↗
Option 2 · Browser Source with the local bridge Advanced setup / transparent overlay

  1. Start the local bridge.

    On the same computer as OBS, download the KOGG project and install Node.js from nodejs.org if needed. From the project folder, run node tools/obs-relay.cjs. Keep that terminal open.

  2. Open the local presenter.

    In Chrome or Edge, open http://127.0.0.1:8766/. This local workspace is separate from the website. Use a library backup to transfer saved work if needed.

  3. Add a Browser Source in OBS.

    In your scene, choose Sources → + → Browser. Keep Local file off, paste the URL below, and set Width and Height to your canvas size—for example, 1920 × 1080. Use 30 FPS if setting a custom frame rate.

  4. Display a verse and check the scene.

    Send Scripture live from the local presenter. Place the Browser Source above your camera source for a transparent overlay. Use Blank in KOGG to clear it. If it stays blank, check the bridge is running, the source is visible and a verse is live; then refresh the Browser Source.

OBS BROWSER SOURCE URLhttp://127.0.0.1:8766/display.html?overlay=1

For a solid slide background, remove ?overlay=1 from the URL.

The website URL alone will not sync your live verses into OBS: OBS uses a separate browser. Keep both the local presenter and bridge running on the OBS computer.

A FEW PRACTICAL ANSWERS

Before the
service starts.

Go to the app ↗
What really works offline?

After the app reports Ready offline, its interface, three core Bibles, Strong’s lexicon and basic hymnary are cached. Saved songs and previously downloaded packs work offline. Connected Bible passages, online lyrics search, sign-in and sync need internet. Browser storage can be cleared or evicted, so check readiness before a service.

Will my work travel to another device?

Use Sync mode and sign in to the same account. Saved songs, service plans, themes and referenced artwork use the existing cloud library. Let the sync complete before leaving, and open the next device online before travelling offline. Imported custom Bible files are device-local; use a full backup to transfer them.

What happens to lyrics in Base mode?

They stay in the current tab’s session workspace, including the draft and temporary Service items. A refresh preserves that workspace. End session clears it without deleting a saved Local/Sync library or the hymn packs. Save in Local or Sync when you want a permanent copy.

Can I use NIV, NLT or an Efik Bible?

Connected NLT and API.Bible translation controls are implemented. They need internet; API.Bible versions also need your own key and suitable account access. Provider limits and terms apply. Efik is not currently bundled. Compatible Bible JSON imports are available in Tools; connected access does not create an unrestricted offline download.

Does the microphone work offline?

The Speak buttons can fill Quick jump and Whole search, and voice commands can navigate the service. Chrome/Edge speech recognition may require internet and microphone permission. Keyboard and touch controls remain available. KOGG does not include music or audio-file playback.

How do I connect a projector or OBS?

Set your displays to Extend and click Output. In Chrome or Edge, allow the screen-management popup so KOGG can place the output on your extended screen and follow it when reconnected. If you previously blocked it, review the site permissions from the browser’s address-bar site controls. KOGG attempts fullscreen where allowed; otherwise click the output once. Ordinary clicks no longer exit fullscreen—press Esc to leave. Some browser setups offer an Automatic fullscreen site setting; it is optional and may not be available. Other browsers may require a manual move. Repeated Output clicks reuse the existing window; the duplicate guard applies within the same site and browser profile. For OBS, the easiest option is Window Capture: select your already-open KOGG Output window. No Node.js or local bridge is needed for that option. For a transparent Browser Source, use the optional local bridge; the hosted app and OBS do not automatically share browser storage. Follow the OBS setup steps. Read the setup guide ↗

Where do online lyrics come from?

Search combines LRCLIB and lyrics.ovh. Google opens as a normal web search; KOGG does not scrape its results. Supported links include Hymnary text pages explicitly marked Public Domain, plus LRCLIB and lyrics.ovh API links. Other pages use copy/paste. Review imported words and keep the supplied credits; source availability does not grant every kind of reuse permission.
